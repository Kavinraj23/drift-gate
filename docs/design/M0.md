# M0 design note: repo skeleton

## What was built
- Packaging (`pyproject.toml`, src layout, package `driftgate`), `.gitignore`, `.env.example`.
- Empty module stubs matching the CLAUDE.md layout, each with a one-line docstring.
- `domain.py`: dataclasses for the PRD types and the full `Report` output contract; `ExecutionSource` / `RemediationTarget` Protocols as in the PRD.
- `contracts/report.schema.json` and `remediation.schema.json`, field for field with enums; tests for valid, bad-enum and missing-field cases.
- `tasks.py` with every CLAUDE.md target. Later-milestone targets print "not implemented (Mx)" and exit 1; human-only targets refuse under `.autonomous`; `mvp-check` prints a check/milestone/status table and exits 1 unless everything passes.
- `llm/fake.py`: scripted test double. Shared request/response types are in `llm/types.py` (an addition to the layout, so the gateway and the fake share one interface without the fake importing the gateway).
- Guardrails: `.claude/settings.json` (allow/ask/deny), Python hooks (`pre_tool_use`, `post_tool_use`, `stop_hook`), `tests/test_hooks.py`.
- Architecture tests and a socket-blocking autouse fixture in `tests/conftest.py`.
- Five subagent definitions, CI workflow, TASKS.md, PROGRESS.md, BLOCKERS.md, IDEAS.md.

## Why
Everything later depends on the guardrails and contracts being fixed first, so they are committed before any feature code. The docs syntax (permissions, hooks, subagent frontmatter) came from the official docs via the claude-code-guide agent, not memory.

## Tested
101 tests pass offline: schemas, fake model, tasks.py behavior, architecture scans, 60 hook cases including Windows paths and the four required Stop-hook cases. `mvp-check` reports M0 pass and M1 to M9a pending (exit 1).

## Open doubts
- The Stop hook's "no new commits" rule is keyed on HEAD stored in `.claude/stop_state.json` (gitignored).
- The pre-tool hook is a text heuristic, not a security boundary (the docs say the same of permission rules). The hook matcher is `Bash|PowerShell`, but the `permissions` allow/ask/deny rules are written for `Bash(...)` only; PowerShell-tool commands rely on the hook alone.
- `Read(./.env.*)` also denies `.env.example`; `cat .env.example` via Bash is still allowed by the hook.
- `ruff format .` reformatted a code block inside `docs/PRD.md` once; reverted, and ruff is now scoped to `src tests tasks.py .claude/hooks`.
- `mvp-check` M2/M4/M6/M7/M8a checks point at test directories that later milestones create.
- The review of M0 that the prompts assign to the human is replaced here by the reviewer subagent, per the user's instruction to run unattended.
